# Period Tracker

A simple command-line period tracker made with beginner Python.

## Features
- Log period start dates
- View your history
- Predict your next period from your average cycle length
- Data saved locally in `periods.json`

## How to run
1. Install Python 3
2. Run: `python period_tracker.py`

## Concepts used
Functions, loops, lists, `datetime`, file reading/writing, JSON, `try/except`.

## Note
This is a learning project, not medical advice. Predictions are simple averages.
